# VOYAGE travel website for EDUSN year 8 ICT project

This website was created as part of a Year 8 school project at EDUSN School, Helio campus. It is a travel website about Myanmar, designed to help both local and foreign tourists easily explore and plan their trips around the country.

## Design

This website follows a minimalist design approach, focusing on clarity and ease of use. The layout uses a clean black-and-white color scheme with just one additional accent color to maintain visual harmony without overwhelming users. Elements are styled with rounded corners to create a modern, soft aesthetic. The interface is kept simple and distraction-free, allowing visitors to focus entirely on content and navigation.
